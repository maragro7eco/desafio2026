2. Análise e Consolidação por Planta

# Crie os blocos de código necessários para processar os dados de grãos, 
# cápsulas e depois uni-los aos dados de laboratório.

# 2.1. Resumir as características dos grãos por planta
graos_resumo <- 
  graos %>%
  mutate(INDIVIDUO = parse_number(img)) %>% 
  group_by(INDIVIDUO) %>% 
  summarise(
    NG = n(),                        # Número total de grãos
    CG = mean(length, na.rm = TRUE), # Comprimento médio dos grãos
    LG = mean(width, na.rm = TRUE)   # Largura média dos grãos
  )

# 2.2. Extrair a característica número total de cápsula das cápsulas por planta
capsulas_resumo <- capsulas %>%
  # Extrair o número da planta do início da string da coluna 'img'
  mutate(INDIVIDUO = parse_number(img)) %>% 
  group_by(INDIVIDUO) %>% 
  summarise(
    NC = n()                         # Número total de cápsulas
  )

# 2.3. Criar o identificador na tabela de laboratório
laboratorio_id <- laboratorio %>%
  mutate(INDIVIDUO = parse_number(as.character(IMG)))

# 2.4. Unificar os dados por planta
dados_planta <- laboratorio_id %>%
  left_join(capsulas_resumo, by = "INDIVIDUO") %>%
  left_join(graos_resumo, by = "INDIVIDUO")

# 2.5. Diagnóstico dos dados ausentes (para inspecionar os indivíduos 8, 9, 10, etc.)
dados_ausentes <- dados_planta %>%
  filter(is.na(NC) | is.na(NG)) %>%
  select(INDIVIDUO, GEN, TIPO, NC, NG)

Conclusão

A análise integrada dos dados fenotípicos, de imagem e de massa permitiu uma avaliação abrangente dos genótipos de linhaça. A exploração visual indicou uma relação positiva entre a altura das plantas e o número de cápsulas, além de evidenciar diferenças fenotípicas importantes entre os tipos Dourada e Marrom, especialmente em relação à altura e à produtividade, apresentando plantas do tipo linhaça Marrom com maior altura média. Por fim, a identificação dos genótipos superiores (Top 5), sendo os genótipos de linhaça Marrom G4 e G2, com MG media 7.04 e 6.32, respectivamente, e de linhaça Dourada G5 e G56, com MG media 5.28 e 5.09, respectivamente, os mais notáveis; e o cálculo do diferencial de seleção demonstraram o potencial de ganho genético para a produção de grãos, fornecendo subsídios consistentes para a recomendação e seleção de variedades mais produtivas no programa de melhoramento.
